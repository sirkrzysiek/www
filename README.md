# Kadry i Płace z Joanną Byczek - Strona Internetowa

Elegancka strona "one pager" dla usług kadrowo-płacowych Joanny Byczek.

## Funkcje

- **Responsywny design** - działa na wszystkich urządzeniach
- **Minimalistyczny styl** - elegancka typografia i dużo przestrzeni
- **Mikrointerakcje** - subtelne animacje i efekty hover
- **Smooth scrolling** - płynne przewijanie do sekcji
- **Menu mobilne** - hamburger menu dla urządzeń mobilnych
- **Animacje scroll** - elementy pojawiają się podczas przewijania
- **Paleta beżowa** - elegancka kolorystyka

## Struktura

1. **Sekcja Hero** - główny nagłówek z zdjęciem
2. **Sekcja O mnie** - informacje o Joannie z wyróżnionym hasłem
3. **Sekcja Usługi** - 4 kafelki z zakresem usług
4. **Sekcja Kontakt** - dane kontaktowe z ikonami

## Pliki

- `index.html` - główny plik HTML
- `styles.css` - style CSS z animacjami
- `script.js` - interaktywne funkcje JavaScript
- `hero-image.jpg` - zdjęcie do sekcji hero (do dodania)

## Instalacja

1. Pobierz wszystkie pliki do jednego folderu
2. Dodaj zdjęcie `hero-image.jpg` do folderu
3. Otwórz `index.html` w przeglądarce

## Dostosowanie

### Kolory
Kolory można zmienić w pliku `styles.css` w sekcji `:root`:
```css
:root {
    --primary-beige: #f5f5dc;
    --secondary-beige: #f0e6d2;
    --accent-beige: #e6d7c3;
    --dark-beige: #d4c4a8;
}
```

### Treść
Edytuj treść w pliku `index.html`:
- Zmień tekst w sekcjach
- Zaktualizuj dane kontaktowe
- Dodaj własne zdjęcie

### Animacje
Animacje można dostosować w pliku `script.js`:
- Szybkość animacji
- Efekty hover
- Typing animation

## Wymagania techniczne

- Nowoczesna przeglądarka z obsługą CSS Grid i Flexbox
- Połączenie internetowe (dla fontów Google i ikon Font Awesome)
